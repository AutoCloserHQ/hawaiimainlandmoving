# HawaiiMainlandMoving.com

Static Hawaii ↔ U.S. mainland moving resource operated by ModelMoving.

Draft implementation on `hawaii-build-v1`. See [REVIEW.md](REVIEW.md) for architecture, verification and launch-review items. No merge or deployment is included.

Serve this directory at a domain root. Production canonical URLs use `https://hawaiimainlandmoving.com/`. No build is required to serve the committed HTML/CSS/JS/assets.

To regenerate content: `python3 tools/build.py`.
